# 🧪 FunLab — Where Curiosity Meets Creativity

FunLab is a chaotic collection of interesting and funny machines, mini games, experiments, funny interactions, and questionable decisions.It is a website where "curiosity meets creativity".In this wbsite,every thing is intersting.It is best for timepass and for relaxing your mind. 

It is designed as a fun and interactive web experience where almost every button does something unexpected.

## 🚀 Features

- 🎮 Interactive mini games
- 🌀 Interesting and chaotic machines
- 😂 Funny interactive experiments
- 💻 Hacker-style terminal
- 🔥 Roast Me feature
- 🐔 Random interactive elements
- ✨ Hover animations and effects
- 🎭 Unexpected button interactions
- 📱 Responsive design for mobile devices
- ⚡ Fast and lightweight frontend
- 🎨 Modern dark/chaotic UI
- 🖱️ Interactive buttons and animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- CSS Animations
- Responsive Design
